# 功能清单（Function Tree）— cs-support-agent

> **本仓唯一锚点。** 需求、设计、测试都引用这里的 ID。
> 不在这里的 ID 是悬空引用。**改功能，先改这份表。**
> 独立配套仓（无家族 mirror），树即终审，变更直接改本文件并 commit。

## 编号规则

| 层级 | 名称 | 格式 | 含义 |
|---|---|---|---|
| 一级 | 功能模块 | `M0x` | 业务域边界 |
| 二级 | 功能 | `M0x.F0y` | 一个完整闭环能力 |
| 三级 | 功能子项 | `M0x.F0y.I0z` | 技术交付单元（一个接口 / 一个页面 / 一个引擎件） |

**硬规则**

1. 编号单调递增，永不复用。废弃改状态，不删行。
2. 子项编号必须以父级为前缀。
3. 拆不出子项的功能 → 它其实是子项，往上并。子项超 20 个 → 它其实是模块，往下拆。

**状态**：`规划` | `开发中` | `已上线` | `已废弃`
**子项类型**：`接口` | `页面` | `组件` | `引擎` | `服务层`

## 本仓定位

智能客服 Agent：**知之为知之**——用户提问，客服先识别意图（查知识库/报障开单/转人工/寒暄），
路由到对应分支；查知识库则本地检索 TopK 片段，答案必须带 [n] 引用并过自我校验
（关键内容与被引片段重叠校验），查不到、意图不明、校验不过都如实承认并转人工。
突出点 = **M02 回答自我校验**——查得到引原文答、查不到绝不编，人工兜底（Agentic RAG 三分支全部真实实现）。
书籍映射：《图解AI Agent》第 12 章收官项目（C032 RAG / C033 向量检索 / C034 知识库 /
C035 Agentic RAG / C036 意图识别 / C037 路由 / C038 自我校验）；
书中 LangGraph+ChromaDB 叙事，本仓按既定纪律改为**手写 Agentic RAG 循环 + 本地词频向量检索**（无网可跑，同等能力）。
架构：FastAPI + OpenAI 兼容直调（MiniMax-M3，可配 base_url）+ React 18 前端。

### M02.F01 引用校验器

| 子项 ID | 名称 | 类型 | 交付 | 说明 | 状态 |
|---|---|---|---|---|---|
| M02.F01.I01 | 引用存在性校验 | 引擎 | 后端 | [n] 必须对应本次检索返回的片段编号；引空/引不存在→校验失败 | 已上线 |

| 子项 ID | 名称 | 类型 | 交付 | 说明 | 状态 |
|---|---|---|---|---|---|
| M02.F02.I01 | 检索无结果分支 | 服务层 | 后端 | 检索返回空 → 如实说「知识库没有」+ 询问是否转人工 | 已上线 |
